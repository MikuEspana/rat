# @rat/db

Database layer. The database is the source of truth. Owned by WS03.

- `schema.ts`: 13 tables. Money in bigint lamports. `mode` column (`paper` | `live`) keeps DRY RUN rows apart from live rows.
- `migrations/`: SQL generated by `pnpm --filter @rat/db generate` (drizzle-kit). Applied with `handle.migrate()`. `0001` adds `ledger_entries.closes_id` (unique): each settle / release names the reservation it closes, so a reservation closes exactly once even after a crash.
- `connection.ts`: `openDatabase(url)` for `postgres://` (production), `pglite://dir` or `memory://` (tests, local).
- `store.ts`: `new Store(db, mode, clock)` with repositories: settings, keys, ledger, attempts, stocks, rats, claims, events, heartbeats, seen signatures, locks.

Ledger rules: `balance(bucket)` is the only money the bot may spend from that bucket. `netOutflowSince(bucket, t)` feeds the per-bucket hourly cap. `lifetimeNetOutflow()` feeds the smoke test cap.

Single worker: `locks.acquire('worker', holder, now, ttl)` is a lease lock (works through poolers and PGlite, expires if a worker dies).
